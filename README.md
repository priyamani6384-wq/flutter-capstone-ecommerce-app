# Mobile App Capstone - E-Commerce Complete App
Final Project - Flutter Fast Track - Codomax

## System Models & Architecture
- MVVM Architecture
- Models: User, Product, Cart
- Navigation: Bottom Nav, Auth Flow
- State: setState (simulating Riverpod/Bloc)

## UI Wireframes
- Auth Screen -> Home Grid -> Cart -> Checkout -> Profile
- Figma: E-commerce layout with search, grid, cart

## Backend Setup
- REST API: Product fetching with JSON parsing
- Firebase: Auth (Email/Pass), Firestore (products, users, orders collections)
- Local DB: Cart persisted (simulated Hive/SharedPrefs)
- Security Rules: auth!= null, read/write if owner

## Hardware Integrations
- Location: Geolocator - delivery address
- Camera Overlay & Gallery: Product review images
- Notifications: Order updates

## Test Build
- APK: flutter build apk --release (Ready)
- Video Demo: Screen recording of full flow

## Features
Full E-commerce: Login, Browse, Search, Add to Cart, Checkout, Profile, Location, Camera
